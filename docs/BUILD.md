# 제작 가이드

프로토타입을 처음부터 만드는 절차. 부품은 전부 범용 유통품이고 특수 공구는 필요 없다.

## 부품

| 품목 | 규격 | 수량 | 단가(원) |
|---|---|---|---|
| 택트 스위치 | 6×6mm, 4핀 | 16 | 134 |
| Arduino Leonardo | ATmega32u4 (USB HID 네이티브) | 1 | 8,500 |
| 가죽 장갑 | 좌우 1쌍 | 1쌍 | 1,000 |
| 단선 케이블 | AWG 26~28 | 1식 | 1,040 |
| 열수축 튜브 | φ2~3mm | 소량 | (배선재 포함) |
| 접착제·절연 테이프 | | 1식 | 500 |
| **합계** | | | **14,184** |

보드는 **반드시 32u4 계열**이어야 한다. USB HID를 네이티브로 지원해야 PC가 이 장치를
일반 키보드로 인식하고, 그래야 드라이버 없이 OS 기본 한글 IME가 조합을 처리한다.
Uno(ATmega328P)는 이 방식이 불가능하다.

## 버튼 위치

한 손에 8개씩, 총 16개를 **엄지가 닿기 편한 마디**에 붙인다.

```
           검지        중지        약지        소지
첫째 마디   ●          ●          ●          ●
둘째 마디   ●          ●          ●          ●(기능키)
```

- 검지~약지는 첫째·둘째 마디 각 1개
- 소지는 첫째 마디 1개 + 둘째 마디에 기능키(왼손 Backspace / 오른손 Space)
- 자모 배치는 [`firmware/keyboard_glove/mapping.json`](../firmware/keyboard_glove/mapping.json)이 단일 출처
- 핀 대응은 [`firmware/keyboard_glove/WIRING.md`](../firmware/keyboard_glove/WIRING.md) 참조

위치는 임의로 정한 것이 아니라, eyes-free 배열 후보 3안을 두고 참가자 30명의 응답과
HCI 문헌을 근거로 선정했다. 버튼을 옮기면 그 근거가 깨지므로, 위치 변경 시에는
`mapping.json`과 실험 결과 해석을 함께 검토해야 한다.

## 제작 순서

### 1. 장갑에 위치 표시
착용한 상태에서 엄지를 각 마디에 대 보며 실제로 편하게 닿는 지점을 표시한다.
손 크기에 따라 위치가 달라지므로 **착용자 기준으로** 잡는다.

### 2. 스위치 부착
**양면테이프와 접착제를 함께 써서 고정한다.** 양면테이프로 표시한 자리에 붙여 위치를 잡고,
접착제로 굳혀 반복 타건에도 밀리지 않게 한다. 스위치가 마디 곡면 위에서 흔들리면 클릭 촉감이
뭉개져 eyes-free 입력의 확인 신호가 약해지므로, 흔들림이 없는지 눌러 보며 확인한다.
누를 때 눌리는 방향이 손가락 축에 수직이 되게 두어야 엄지 힘이 그대로 전달된다.

### 3. 배선
배선은 **손등 방향으로** 빼서 보드까지 잇는다. 손바닥 쪽으로 지나가면 물건을 쥐거나 주먹을
쥘 때 눌려 오작동하고 착용감도 나빠진다.

- 각 스위치의 한쪽 다리 → 지정 디지털 핀
- 반대쪽 다리 → **GND 공통선**(손별로 묶어 한 가닥으로 보드에 연결)
- 외부 풀업 저항은 쓰지 않는다. 펌웨어가 `INPUT_PULLUP`으로 읽는다
- 손가락을 구부릴 때 배선이 당겨지지 않도록 마디 사이에 여유를 준다

### 4. 절연·마감
납땜부는 열수축 튜브로 감싸고, 손등 쪽 배선은 테이프로 정리해 걸리지 않게 한다.

### 5. 펌웨어 업로드
Arduino IDE에서 보드를 **Arduino Leonardo**로 선택하고
`firmware/keyboard_glove/keyboard_glove.ino`를 업로드한다.

### 6. 동작 확인
메모장을 열고 각 버튼을 눌러 의도한 자모가 나오는지 확인한다.

| 증상 | 확인할 것 |
|---|---|
| 특정 버튼이 반응 없음 | 해당 핀 납땜, GND 공통선 연결 |
| 한 번 눌렀는데 두 번 입력됨 | 스위치 접점 불량 → `DEBOUNCE_MS` 상향 검토 |
| 연타가 안 합쳐짐 / 너무 잘 합쳐짐 | 연타 판정 윈도우 → 캘리브레이션 수행 |
| 엉뚱한 자모가 나옴 | `mapping.json`과 실제 배선 핀 대응 |

### 7. 사용자별 캘리브레이션
```bash
python firmware/keyboard_glove/tap_calibration.py
```
문장 두 개를 입력하면 개인의 연타 간격 분포를 실측해 판정 윈도우를 정하고 펌웨어에 기록한다.
착용자가 바뀌면 다시 수행한다.

## 개선 시 유의할 점

폼팩터는 바꿔도 되지만 **매핑 메커니즘은 건드리지 않는 것**이 원칙이다.
스위치 촉감·장갑 소재·무선화는 입력 방식과 독립적인 계층이라 자유롭게 교체할 수 있는 반면,
버튼 위치와 자모 배치를 바꾸면 실험 결과의 근거가 함께 무효화된다.

- **무선화**: Bluetooth HID 모듈 + 소형 PCB로 32u4 직접 실장 (원가의 60%인 보드값도 함께 절감)
- **사이즈 전개**: 손 크기 개인차를 고려해 S/M/L
- **소재**: 가죽 → 경량·통기성 소재, 세탁 가능성 확보
- **스위치**: 동일 풋프린트를 유지하면서 클릭감이 명확한 제품으로 교체
